## 每个站点的通过条件

一个站点只有同时满足以下条件，才可以标记为“真实回归通过”：

1. 当前 URL 被正确识别为目标 adapter，不能意外回退到 `generic`。
2. 能扫描至少三个核心字段，并在面板显示站点徽标。
3. 至少一个姓名、电话、邮箱、城市、学历或职位字段真实写入页面。
4. 至少覆盖一个站点特殊行为：搜索下拉、级联城市、动态经历、分步按钮或附件上传。
5. 至少验证一个失败或安全边界：非法值、跨域 iframe、验证码/登录限制或最终提交按钮不被自动点击。
6. 记录浏览器、站点 URL（去除查询参数）、扫描字段数、填写结果和失败原因；日志不得包含 token、API Key 或完整个人简历。

## 开发命令

- 脱敏夹具：`npm test -- --run tests/site-form-fixtures.test.ts tests/ats-form-fixtures.test.ts`
- Chrome/Edge 扩展：`npm run test:e2e:extension`
- Firefox：`npm run test:firefox:runtime`
- 开发门禁：`npm run verify`
- 本机最终门禁：`npm run verify:full`

真实站点验证必须使用用户有权访问的页面。遇到登录、验证码、跨域 iframe 或站点安全策略时记录限制，不尝试绕过。
